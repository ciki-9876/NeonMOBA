# NEON DRIFT · 角色机制设计

> 状态：第一版（2026-11-26），已确认。
> 回答三个问题：一个角色的哪些属性有机制作用、这些属性怎么变化；角色的剧情走向由什么决定；国籍和性别的规则。
> 协作者怎么批量制作角色，见 `角色设计规范.md`。具体角色见 `角色设定初稿_第一赛季.md`。

## 一、属性总表

角色的属性分五类。原则：**每个属性至少驱动一个系统**；驱动不了系统的设定只写在背景文字里。

| 类别 | 变化快慢 | 属性 |
|---|---|---|
| A. 设定 | 几乎不变 | 性别、国籍、语言、年龄、职业位置、性格五项、潜力、成长曲线、擅长英雄 |
| B. 成长 | 赛季级 | 六项能力、英雄熟练度、特质、名气 |
| C. 状态 | 周级 | 疲劳、状态、满意度、磨合度 |
| D. 关系 | 事件级 | 和其他角色的关系值 |
| E. 合同 | 谈判时 | 合同年限、薪资、条款、身价（计算得出） |

### 详表

图例：**战**＝影响比赛战力，**事**＝影响事件和剧情触发，**经**＝影响经济和转会，**社**＝影响队内关系。

| 属性 | 范围 | 影响 | 由谁改变 | 玩家能否看到 |
|---|---|---|---|---|
| 性别 | 男 / 女 | 只用于叙事和人称，**不影响任何数值** | 不变 | 是 |
| 国籍 | 国家 | 社：语言默认值；经：所在地区的粉丝基础（赞助，之后做）；事：签证、回国、国家荣誉类事件 | 不变 | 是 |
| 语言 | 每种语言 0–3（不会 / 简单 / 能交流 / 母语） | 战：队内沟通（第五节） | 时间（和说这种语言的队友相处）、事件、教练 | 是 |
| 年龄 | 岁 | 训练成长速度、成长曲线所处阶段、退役概率 | 每个休赛期 +1 | 是 |
| 职业位置 | 坦克 / 输出 / 辅助 | 只能首发这个位置 | 极少数事件（转位置） | 是 |
| 性格五项 | 各 0–10 | 事、经、社（第三节） | 只有重大剧情选择能改，每次 ±1 | **否**（从言行推断；高级球探报告能看到大概） |
| 潜力上限 | 开局在区间内抽定 | 能力平均值的天花板 | 事件（顿悟 +1~2，伤病 −1~2）；训练**不能**提高 | 否（球探给出估计范围） |
| 成长曲线 | 早熟 / 标准 / 晚成 / 昙花 | 自然成长和衰退的时间 | 不变 | 否（年龄和表现能看出来） |
| 擅长英雄 | 1–3 个 | 战：发挥 +0.6 能力分、专属能力；熟练度成长 ×2 | 极少数事件（顿悟） | 是 |
| 六项能力 | 各 1–20 | **战**：比赛 AI 的执行质量（`hero_ai.gd` 的 `apply_profile`） | 训练、自然成长或衰退、事件、教练和设施的倍率 | 是 |
| 英雄熟练度 | 每个英雄 0–100 | 战：熟练度阶段系数（生疏 0.87 … 大师 1.03） | 训练、比赛中使用、长期不用的衰减 | 是 |
| 特质 | 0–3 个 | 战：特定情境下的修正（残局、大赛……） | 事件和里程碑可获得或失去 | 是 |
| 名气 | 0–100 | 经：身价、薪资要求；事：媒体事件、被挖角的频率；社：和自尊叠加影响队内地位 | 比赛结果、奖项、高光、新闻、丑闻 | 是 |
| 疲劳 | 0–100 | 战：≥70 能力 −1，≥90 −2；训练效率 | 训练 +14、比赛 +6、每周自然 −12、休息 −35（已实现） | 是 |
| 状态 | −3 到 +3 能力分 | 战：比赛中所有能力加减 | 最近比赛表现（MVP、连胜、连败、被单杀）、事件；每周向 0 回归 | 是（用「火热 / 正常 / 低迷」显示） |
| 满意度 | 0–100 | 事：低于 30 触发要求转会、消极训练等事件；经：续约折扣或加价；被挖角的难度 | 第三节的公式，每周更新 | 部分（显示为心情图标） |
| 磨合度 | 和现队友在一起的周数 | 战：新加入的人配合 −2，6 周内恢复到 0 | 每周 +1；转会清零 | 是 |
| 关系值 | 每对角色 −100 到 100 | 战：同队的朋友配合加成、不和则减；事：宿敌、师徒、背叛等事件 | 事件、同队的胜负经历、转会和合同纠纷 | 部分（亲近 / 普通 / 紧张 / 敌对） |
| 合同 | 年限、周薪、违约金、条款 | 经：工资支出、转会费；事：到期前的续约事件 | 谈判 | 是 |
| 身价 | 计算得出 | 经：转会报价的基准 | 由能力、潜力估计、年龄、名气、合同剩余年限算出 | 是 |

## 二、战力管线：一名选手上场时的实际水平

不管是实机比赛还是直接出结果，都用同一个「上场面板」，算法按顺序叠加：

| 步骤 | 内容 | 代码位置（现状 / 计划） |
|---|---|---|
| 1 | 六项能力面板 | 选手数据 |
| 2 | × 熟练度阶段系数（心态除外） | `Profiles.effective`（已有） |
| 3 | − 疲劳惩罚（0 / 1 / 2） | `Training.in_form`（已有） |
| 4 | + 状态（−3 到 +3） | 计划：并入同一个「上场面板」函数 |
| 5 | 配合 + 队内修正：沟通（语言）、磨合度、同队关系 | 计划 |
| 6 | 擅长英雄：发挥 +0.6、专属能力生效 | 已有 |
| 7 | 特质：按比赛中的情境生效（例如残局之王在只剩一人时 +3） | 计划（比赛中） |
| 8 | 心态：压力局面重新抽取能力波动 | 已有（`hero_ai`） |

- 第 3–5 步只改「上场面板」的副本，不改选手本身的数据。
- 第 5 步的修正只作用在「配合」上：它决定集火、控制接力、跟进开团，正好对应「队伍不熟、语言不通、关系不好」的表现。
- 玩家亲自操控主角时，反应、操作、意识、决断由玩家本人替代，配合和心态仍然生效（核心对战规则已定）。
- 直接出结果（`quick_sim`）的队伍强度用上场面板的平均能力，这样状态、疲劳、磨合在两种模式下效果一致。

## 三、属性怎么变化：按系统列

| 系统 | 改变哪些属性 | 规则要点 |
|---|---|---|
| **训练**（已实现） | 能力、熟练度、疲劳 | 每周一项；年龄越小成长越快；不能突破潜力上限 |
| **年龄曲线**（每个休赛期） | 能力、退役 | 巅峰前：向潜力上限自然成长约 +0.3–0.8；巅峰后约 3 年开始衰退约 −0.5–1.5，反应和操作先降，意识和决断最后降；28 岁后退役概率逐年上升（满意度低、名气低时更高） |
| **比赛** | 熟练度、名气、状态、疲劳、关系 | 上场的英雄熟练度小幅上涨；MVP 和高光提高名气和状态；同队一起赢下关键比赛，队友之间关系 + |
| **满意度**（每周） | 满意度 | 见下面的公式 |
| **事件** | 任何属性 | 剧情选择的后果；性格每次最多 ±1 |
| **教练和设施**（之后做） | 训练倍率、状态回归、满意度 | 例如「心理咨询师」加快状态回归 |
| **转会和合同** | 所属、合同、磨合度、关系、满意度 | 被卖掉的人对原队关系 −；被挖来的人磨合度清零 |
| **媒体** | 名气、状态、关系 | 论坛热帖、采访嘲讽：自尊高的人状态波动更大，宿敌关系加深 |

**满意度**每周向目标值移动，目标值由五部分组成，每部分的权重由性格决定：

| 组成 | 公式要点 | 权重来自 |
|---|---|---|
| 上场时间 | 首发 +，替补 −；连续坐板凳越久越低 | 野心 |
| 战队成绩 | 排名、连胜连败 | 野心 |
| 薪资 | 薪资 ÷ 按身价应得的薪资 | 物欲 |
| 队内关系 | 和队友关系值的平均 | 合群 |
| 尊重 | 被公开批评、被替换、被当作交易筹码 | 自尊 |

忠诚高的人满意度下降更慢。满意度低于 30 时，按性格触发通用事件：要求转会、训练消极、接受其他战队的私下接触。

## 四、剧情走向由什么决定

### 1. 五个驱动因素

| 因素 | 例子 |
|---|---|
| **原本轨迹**（基线） | 前世的历史：小鱼 S1 后被天穹签走 |
| **世界状态** | 战队成绩、阵容、财务、积分榜、谁在哪支队 |
| **角色状态** | 满意度、关系、名气、状态、性格 |
| **玩家选择** | 剧情事件里的选项、转会、训练、上场安排 |
| **随机** | 事件概率、潜力抽取、比赛结果 |

### 2. 三层事件

| 层 | 来源 | 例子 | 谁来写 |
|---|---|---|---|
| **专属事件**（原本轨迹） | 核心角色的原本轨迹，每条带前提条件和概率 | Rex S2 第 4 周和老板闹翻 | 角色作者 |
| **通用事件** | 由状态触发的模板，任何角色都可能遇到 | 坐板凳 3 周 + 野心高 → 要求转会；两人关系 < −50 且同队 → 训练室冲突 | 系统设计，一次写好全员复用 |
| **世界事件** | 联盟层面 | 扩军、赞助商暴雷、版本更新、假赛丑闻 | 世界年表作者 |

### 3. 偏离的规则（蝴蝶效应）

- 每条原本轨迹事件都有**前提条件**。到了时间点，条件满足就按概率发生；条件不满足就不发生。
- 原本轨迹不发生后，这个角色交给**通用事件**和 AI 决策接管。例如小鱼没被天穹签走，那他之后的人生由他在星火的满意度、关系、成绩决定。
- 一个事件没发生，可能导致后面依赖它的事件也不发生。例如 Rex 没去天穹，「天穹 S3 夺冠」的前提（阵容实力）就可能不成立。世界事件的前提要写成**实力或状态条件**，不要写成「某事件已发生」，这样即使历史偏离，世界也能自洽运转。

### 4. 前世笔记的状态

每条笔记绑定一条原本轨迹事件，状态自动计算：

| 状态 | 条件 | 显示 |
|---|---|---|
| 待发生 | 时间未到，前提仍然满足 | 正常 |
| 不确定 | 时间未到，前提已有部分变化（例如当事人换了队） | 灰色加问号 |
| 已应验 | 事件发生了 | 打勾 |
| 已改变 | 前提不满足，事件没有发生 | 划掉 |

### 5. 结局

每个核心角色写 2–4 个可能的结局（例如小鱼：顶级辅助、重蹈覆辙、转型教练），每个带达成条件。生涯结束时按条件判定，在生涯结算里展示「你改变了谁的命运」。

### 6. 节奏控制

- 每周最多 1 个大型剧情事件（剧情插图或需要选择）和 2 个小事件（私信、热帖）。
- 优先级：玩家战队的核心角色 > 宿敌和对手 > 世界上的其他人。
- 同一个角色的事件之间至少隔 2 周（专属事件除外）。

### 例子：小鱼的走向

1. 原本轨迹：S1 休赛期天穹报价（前提：小鱼还在星火）。
2. 玩家在 S1 让星火打进季后赛，小鱼的满意度高、和主角关系高。
3. 报价事件照常触发（前提满足），但「让小鱼自己决定」时，他按满意度和忠诚选择留下。
4. 原本轨迹里「在天穹坐板凳三年」的后续全部失效，笔记标为「已改变」。
5. 之后他的走向由状态决定：成绩好、关系好 → 走向「顶级辅助」结局；如果玩家签了 Mute 并让她首发，小鱼坐板凳 → 满意度下降 → 可能触发「要求转会」通用事件，走向另一条线。

## 五、性别和国籍

- **性别比例**：所有有名字的选手里，女性约占 1/3（男女 1:2），按全体统计，不要求每支队都有女性。性别只影响叙事，不影响任何数值。
- **国籍**：联赛是国际性的，俱乐部不绑定国籍，选手来自各个国家。国籍决定默认语言，以后还会影响地区粉丝和赞助。
- **语言与沟通**：
  - 每名选手会若干种语言，每种 0–3 级。
  - 两名首发之间的沟通 = 两人共同语言里较低一方的最高等级。
  - 全队沟通取三对首发的平均：3 → 配合 +0；2 → −0.5；1 → −1.5；0 → −3（能力分，只作用于配合）。
  - 语言会随时间提升：在队里每 10 周左右，和队友常用语言 +1 级（合群高的人更快）；也可以通过事件或请语言老师（设施）提升。
  - 设计意图：签外籍明星有代价，需要磨合；同语言的选手组队更容易。
- **外援名额**：不设。

## 六、已确认（2026-11-26）

1. 满意度、状态、磨合度、语言四个状态量都做。
2. 性格对玩家隐藏，只能从言行推断（高级球探报告能看到大概）。
3. 巅峰前每个休赛期自然成长 +0.3–0.8。
4. 不设外援名额。
