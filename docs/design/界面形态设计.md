# NEON DRIFT · 界面形态设计（草案）

> 状态：草案，待确认。来源：玩家流程草稿与剧情呈现讨论。
> 原则：大部分经营界面模拟真实设备，增加代入感的同时降低美术成本；剧情演绎统一形式；战场沿用现有引擎。

## 一、四种核心形态

| 形态 | 说明 | 美术成本 |
|---|---|---|
| 模拟电脑 | 窗口化的经营界面，信息密集，用于决策 | 低：统一窗口框架，内容由数据驱动 |
| 模拟手机 | 竖屏聊天、论坛、新闻、通知，用于社交和即时信息 | 低：统一气泡和卡片组件 |
| 剧情演绎 | 像素插图配文字，用于开场、重生、夺冠、宿敌等剧情节点 | 中：每个节点几张插图，可复用 |
| 对战战场 | 现有回合制 3V3 引擎，亲自上场和训练小游戏共用 | 已有 |

## 二、电脑与手机的分工

**模拟电脑**（重决策）：赛程与积分榜、数据中心、战队管理（选手资料、训练安排）、转会市场与合同后台、财务报表与赞助邮件、符文配置与英雄资料库、对手情报与比赛录像。

**模拟手机**（轻量、即时、社交）：私信和群聊（队友、经纪人、对手、老板）、论坛与热搜、直播间与弹幕、通知推送（报价、丑闻、伤病）、日历与行程、赛事竞猜。

**跨形态的功能**：转会谈判两边都有。电脑上看数据并出价，手机上和选手或经纪人聊。

## 三、需要单独设计的界面

### 1. 基地 / 网吧场景（主界面）
- 一张像素风的房间图，电脑和手机作为可点击的物件放在其中。点电脑进入电脑形态，点手机进入手机形态。
- 承载"情绪价值"成长线（基地装修、奖杯墙、外设升级），玩家能直接看见投入的结果。
- 从网吧角落逐步升级为豪门训练基地，本身就是逆袭的视觉证明。
- 美术：每个基地阶段一张房间图，加可替换的摆件。
- **优先级最高**：它决定玩家每次回到主界面看到什么，也决定经营系统的入口组织，需要尽早定。

### 2. 比赛日 / 转播包装
- **禁选界面**：赛事转播风格。两队选手头像分列两侧，禁用位和选人位放中间，带倒计时。
- **观战模式**：复用战场场景，换一套转播 HUD，包括比分条、解说字幕、双方经济。主角坐替补席时，这里就是队长视角：可以在购买阶段换人，用战术暂停和标记指挥。
- **系列赛结算**：比分、MVP、数据，转播风格的定格画面。

### 3. 训练模式小游戏
- 弹幕关卡、技能命中挑战等，复用战场引擎，但规则和 HUD 不同（计分、评级、目标提示）。
- 进入方式：电脑上打开训练软件，作为过渡。

### 4. 局外层："记忆空间"
- 标题画面、存档选择、开局身份选择、生涯结算、名人堂、前世记忆解锁树。
- 统一包装为"两次人生之间"的空间：暗色背景加碎片化的像素插图，画风与剧情演绎一致，但交互更多。

### 5. 系统层与通用组件
- **系统设置**：暂停菜单、音量、画面、按键、存读档。独立于游戏世界，保证随时可用、一眼能找到。
- **通用组件**：确认弹窗、新手引导提示、成就弹出、加载过渡。三种形态共用一套样式。

## 四、剧情呈现（开场）

建议采用"必输的教程 + 像素插图 + 游戏内社交界面"的组合：

1. **教程即前世最后一场比赛。** 玩家亲手打一场必输的比赛（队友失误、被碾压），同时学会 WASD、技能、占点和复活。结束时画面定格。
2. **前世落幕**：3–4 张像素插图配文字，如空荡的网吧、解约通知、多年后看着曾经的对手捧起冠军奖杯。
3. **重生**：同样用插图配文字。醒来发现回到多年前，手机日期和网吧海报都是当年的样子。
4. **回到游戏界面**：剩余剧情通过手机和网吧场景交代，如队友私信、论坛热帖、赛前采访、直播弹幕。

优点：教程本身有代入感，重生后的逆袭更有分量；电竞题材与社交媒体天然契合，宿敌嘲讽和打脸可直接用热帖呈现，建在现有新闻系统上，几乎不增加美术成本。

## 五、美术量估算（开场阶段）

- 剧情插图：开场 6–8 张，后续每个剧情节点约 2–4 张。
- 角色半身像：主要角色各几张表情。
- 基地房间：每阶段 1 张，加若干摆件。
- 电脑与手机：统一窗口框架和组件，内容由数据驱动，不逐屏做图。
