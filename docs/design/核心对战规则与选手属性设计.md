# NeonMOBA · 核心对战规则 v2 与选手属性设计（已确认）

> 状态：设计已确认，阶段 1 原型已实现（回合制、占领核心、经济、选手能力接入 AI、校准）。取代原「生存刷怪 + 3V3 竞技场」两阶段方案。原生存模式转为经营层的训练模式。

## 一、核心对战：回合制 3V3

- **赛制**：BO3 系列赛；每张地图先赢 4 回合（最多 7 回合）。赛前先禁选地图，再禁选英雄（每队禁 2 选 3）。
- **回合**：每回合 75–100 秒，开局有 15 秒购买和布阵。每回合开始时所有技能冷却重置。
- **地图机制即获胜条件**：一张地图对应一种机制，后续逐步扩充。全歼对方在任何机制下都直接获胜。
  - 占领核心（首个）
  - 待做：护送载荷、击破水晶、抢夺能量球、坚守倒计时
  - 不同机制偏好不同阵容，地图禁选因此是博弈的一环。
- **没有局内升级、小兵和打钱**。英雄成长只来自装备。
- **装备**：
  - 6 格；输掉回合或阵亡都不会损失装备。
  - 12 基础件 → 15 成品 → 6 终极件，外加特化芯片（不占格）和终极协议两件英雄强化；终极件和强化承担后期的「钱袋」（2026-11-25，见 `属性与装备迭代设计案.md`）。
- **经济**（2026-11-25 调整，原为胜方 +2500、败方 1500/2000/2500/3000）：
  - 胜方每回合固定 +2000。
  - 败方按连败数 +1500 / 2000 / 2500 / ……（每多连败一回合 +500，不封顶）。
  - 败方每次输掉回合后，可以一次性按 100% 原价出售装备，用于转型针对对方。
  - **实测**（两队能力和阵容相同，各 60 张地图，同一批种子）：
    - 4:0 横扫：33% → 8%；
    - 输掉一回合的一方赢下下一回合：38% → 55%；
    - 平均每张地图回合数：5.2 → 5.8。
    - 注意：同时上线了 AI 的针对出装，见下。
- **AI 针对出装**：
  - 输掉回合后，AI 统计本队目前为止承受的伤害类型：物理占 60% 以上就补物防（坦克买反应装甲，其他人买纳米装甲片），法术占 60% 以上就补法防（坦克买屏障发生器，其他人买相位涂层）；对方治疗量高时买重创注射器（坦克买破甲钻头），对方前排有效生命很高时物理输出买破甲钻头。
  - 钱不够时，用「原价卖一件」卖掉最不对路的装备来凑钱。
  - 实测：会针对出装的一队对固定出装的一队，地图胜率 57%。
  - 2026-11-25 装备重做后补上了「重伤」「破甲」「韧性」三种针对手段（上面的规则已包含前两种；韧性在坦克的常规出装里）。
- **技能**：保持冷却机制，不使用大招充能点，保留英雄设计的灵活性。

| 英雄等级 | 固定 12 级，技能自动加点 | |

| 初始金钱 | 3000 | |
| 击倒 / 助攻 | +150 / +50 | 原设计没有，原型先加上以鼓励交战，可删 |

AI 在核心开放前会守住卡位线，只有明显占优（战力 ≥ 对方 1.3 倍）才开团。核心开放后：
- 阵型收进核心；
- 我方无人在点而对方在点时，离核心最近的人直接走进去；
- 不追出核心太远；
- 低血量只做短暂脱离，不回泉水（回合制没有泉水，也不复活）。

### 地形与草丛（2026-11-25 加入，`game/maps.gd`、`game/terrain.gd`）

目的：让占点地图有进场路线和位置的博弈，同时不让 AI 变得难做。所以只做「地形 + 草丛」，不做完整的战争迷雾（视野不限距离，只有草丛会藏人）。

**地图「核心 · 立柱」**（默认）：
- 核心周围 4 根立柱（半径 58，位于 (±400, ±250)）；
- 上下两道长墙（x −300 到 300，y ±520 到 ±580），墙外是两条侧翼通道；
- 6 块草丛：两侧通道中间各一块大草丛 (0, ±800)，四个出生口斜前方各一块小草丛 (±640, ±470)。
- 另保留「核心 · 开阔」（无地形）作对照，开局菜单可选。

**规则**：
- 立柱和墙挡移动、挡视线、挡弹道技能；位移技能撞墙停下；普攻和指定目标技能需要视线。已经飞出的普攻弹道仍然必中。
- 站在草丛里的英雄对方看不见、不能被选为目标，除非：对方有人在同一块草丛里或 150 范围内；或者他在 1.2 秒内攻击过或放过技能。范围伤害照样能打中草丛里的人。
- 画面只画玩家队伍看得见的对手（模型、血条、小地图都隐藏）；我方在草丛里的英雄半透明。

**AI 怎么用地形**：
- 寻路：直线被挡时走网格寻路（40 像素格，按英雄半径膨胀障碍）。
- 被挡视线的目标降低优先级；没有视线时不朝目标放进攻技能。
- **进场路线**：每回合团队选一个卡位点，一半概率走中路正面，一半概率藏进本方一侧的小草丛，核心开放后从墙端绕进来。输掉一回合后倾向换路线（意识越高越会换）。
- **记忆**：对手进草丛后，团队还会把他算进战力，记忆时长随意识 1.5 → 7 秒。对手在附近草丛消失时，坦克去探草丛；有对手从开局就没露面时，意识高的队伍会在核心开放前探附近的草丛。
- **掩体**：被追击时（追兵 480 内），按意识概率躲到能挡住追兵视线的立柱或墙后。每次撤退最多躲 1.8 秒，之后回到队伍，避免躲着不打。

**实测（两队英雄相同，各 40 局）**：

| 测试 | 「立柱」地图 | 「开阔」地图（对照） |
|---|---|---|
| 能力相同 | 胜率在 45–55% 之间 | 同 |
| 能力差 2（12 对 10） | 60% | |
| 能力差 5（16 对 11） | 85% | 原校准 78% |
| 只差意识（18 对 6） | 70–75%；掩体使用 23 秒/图 对 6 秒/图 | |
| 回合结束方式 | 占领约 75%、全歼约 15%、时间到约 10% | 占领约 60%、全歼约 20%、时间到约 15% |
| 进场路线胜率 | 中路约 45%，侧翼草丛约 53–60% | |

**观察和待办**：
- 意识终于有了地形上的独立指标（掩体使用、探草丛）。
- 地形让占领结束的比例上升：躲掩体减少了换血。限时躲掩体后从 83% 降到 75%，仍高于开阔地图。如果想要更多团灭，可以缩短掩体时间，或给墙后增加回血之外的代价。
- 侧翼草丛路线略占优（约 55%），但还不是必胜解；探草丛在实战中触发很少，因为侧翼草丛在对方半场。阶段 2 加禁选、地图选择时再复核。

## 二、选手属性（四层）

### 1. 通用能力（6 项，1–20 分）：决定 AI 的执行质量

每项能力必须对应可量化的对战指标。批量模拟时，提升单项能力必须能在对应指标上观测到变化，否则视为没有接入，需要修正或删除。

| 能力 | 驱动的 AI 行为 | 验证指标 |
|---|---|---|
| 反应 | 躲预警技能的概率和延迟；被突进后交保命技的速度 | 可躲技能的躲避率；被控到交技能的延迟 |
| 操作 | 弹道瞄准误差（aim_err）；连招衔接；取消前后摇 | 弹道技能命中率；连招完成率；单位时间伤害 |
| 意识 | 目标优先级判断；站位是否避开对方技能范围；察觉侧翼 | 对高优先级目标造成的伤害占比；在可避免位置承受的伤害 |
| 决断 | 撤退血线（不再固定为 0.18）；开团时机；是否过度追击 | 冒进阵亡率；开团成功率；残血撤退成功率 |
| 配合 | 响应集火和开团指令的延迟；控制接力是否叠控；保护队友 | 集火重合度；控制重叠浪费时间；对标记指令的响应延迟 |
| 心态 | 压力情境（赛点、残局、连败）下其余五项的波动幅度 | 压力回合与普通回合的指标差 |

玩家亲自操控某名选手时：反应、操作、意识、决断由玩家本人替代；配合和心态继续作用于 AI 队友，决定队友对玩家标记的响应。

#### 阶段 1 的实际实现（`hero_ai.gd` 的 `apply_profile()`）

**换算方式**：能力先换算到 0–1：`(11 + (能力 × 熟练度系数 − 11) × 灵敏度 − 1) / 19`。11 视为平均选手。灵敏度用于校准：阶段 1 为 1.2，3C 重构后为 0.35，12 英雄全阵容复核后为 0.55（见第四节）。

| 能力 | 实现的行为（0 → 1） | 对应指标 |
|---|---|---|
| 反应 | 思考间隔 0.45 → 0.10 秒；看到预警圈或飞来的弹道时躲开的概率 0 → 90%（施法中不躲） | 躲避率（19 对 11：89% 对 48%） |
| 操作 | 弹道瞄准误差 140 → 6；连招权重；出手犹豫（低操作时决定放技能后有一定概率晚一拍） | 弹道命中率（89% 对 82%） |
| 意识 | 选目标的判断噪声 70 → 0；核心开放后守点的纪律 35% → 100%（不追出核心、及时回点） | 核心停留时间、伤害分布 |
| 决断 | 撤退血线误差 60% → 4%；后排提前冒进的概率；团队大脑对双方战力的误判（按全队平均决断） | （暂无独立指标，见下） |
| 配合 | 跟随团队集火 35% → 100%；控制不叠加；开团跟进延迟 1.2 → 0 秒；脱离阵型单独行动的概率 45% → 0 | 集火伤害占比（67% 对 62%） |
| 心态 | 赛点、或我方只剩一人时，重新抽取其余 5 项的波动：心态越低波动越大，均值越偏负 | （只在压力局面生效） |

**性格随机按时间窗口抽取**：选目标噪声、是否跟随集火、撤退误差、是否守点等随机，每 2–3 秒才重抽一次，而不是每次思考都抽。这样思考更快只意味着反应更快，不会更频繁地换目标或无故撤退。

### 2. 英雄熟练度（每个英雄单独计）

| 阶段 | 能力发挥系数 | 解锁的 AI 打法 |
|---|---|---|
| 生疏 | 87% | 大约一半时间只按技能最主要的用途使用；不打连招 |
| 熟悉 | 94% | 技能的所有推断用途都会使用；不打连招 |
| 精通 | 100% | 主动打连招（prefer_status / setup_status） |
| 大师 | 103% | 发挥系数更高（**不再**解锁招牌特质） |

发挥系数已按校准结果调整：原设计为 70/85/100/105%，实测生疏只剩 17% 胜率，偏离目标太多。

- **专属能力只属于擅长英雄**（见 `经营与养成设计.md` 第四节），不由熟练度解锁。
- **衰减**：长期不使用的英雄熟练度会缓慢下降；擅长英雄衰减更慢。

### 3. 特质（每人 1–3 个）

在特定情境下触发的修正，用来制造故事，例如：残局之王、大赛型、慢热、开团手、英雄池狭窄。

### 4. 状态

- 心态值在比赛中实时浮动：被单杀、连败会下降，残局获胜、高光击杀会上升。
- 偏离常态时，各项能力随机波动的幅度变大。
- 战术暂停（每张地图 2 次）可以拉回心态。

## 三、训练模式（原生存模式）

- **英雄训练**：提升指定英雄的熟练度（擅长英雄 ×2）。
- **能力训练**：
  - 弹幕关卡 → 反应
  - 优先目标关卡 → 意识
  - 技能命中挑战 → 操作
  - 三人小队训练 → 配合
- **取舍**：训练时间按周限量，熟练度会衰减。
- **玩家亲自训练**：按表现评分转换成成长值，效率高于自动训练。

## 四、验证目标（批量 AI 对 AI 模拟）

1. **能力差距与胜率**：平均能力差 2 分时胜率约 60%，差 5 分时约 80%；爆冷率 20–30%。
2. **熟练度**：同一选手用生疏英雄和精通英雄，胜率差约 10–15%。
3. **单项能力**：6 项能力单独提升时，都要在各自的验证指标上有可观测的变化。

工具：`sim/sim_cli.gd`（`--mirror` 两队用相同英雄，只比选手能力）和 `tools/run_curves.py`。

### 阶段 1 校准结果（2026-11-25，两队英雄相同，每项 60 张地图）

| 测试 | 地图胜率 | 回合胜率 | 目标 |
|---|---|---|---|
| 能力相同（11 对 11） | 50%、53%（两组种子） | 48%、52% | 50% |
| 能力差 2（13 对 11） | 62% | 60% | 约 60% ✓ |
| 能力差 5（16 对 11） | 78% | 70% | 约 80% ✓ |
| 能力差 8（19 对 11） | 78% | 73% | 继续拉开差距后趋于平缓 |
| 生疏对精通 | 系数 0.85 时约 29%（120 张），0.90 时 47%；**定为 0.88，预计约 35–40%，待大样本复核** | | 胜率差约 10–15% |

**单项能力（19 对 11，30 张地图）**：
- 各项能力都能让自己的指标变化（躲避率、命中率、集火占比）；
- 单独提升一项对胜率的影响都不大，地图胜率在 50–63% 之间，其中意识最明显；
- 综合起来才形成上面的曲线。

### 3C 重构后的重新校准（2026-11-25，首批 3 个英雄霜铠 / 烬星 / 潮歌，两队英雄相同，A 队左右边交替）

3C 下瞄准误差（操作）和躲避（反应）作用在每一发普攻上，能力差距的影响变大。灵敏度保持 1.2 时曲线严重过陡，0.7 时仍然偏陡：

| 测试 | 灵敏度 0.7 | 灵敏度 0.35（采用） | 目标 |
|---|---|---|---|
| 能力相同 | 40%（20 张） | 60%（10 张，属正常波动） | 50% |
| 能力差 2（13 对 11） | 77%（30 张） | **60%**（30 张） | 约 60% ✓ |
| 能力差 5（16 对 11） | 83%（30 张） | **83%**（30 张） | 约 80% ✓ |

- 各项指标仍随能力变化（差 5 时）：普攻命中 58% 对 55%，躲普攻 54% 对 47%，技能命中 67% 对 63%，集火占比 54% 对 49%。
- 回合结束方式：占领约 70%、团灭约 28%、时间到约 2%；开战阶段中位数约 50 秒；每回合约 2.4 次击倒。
- 单独只差意识（18 对 6）时胜率约 50%，意识对胜负的独立影响变弱，后续阶段再看要不要加强。
- **9 英雄全阵容复核**（两队英雄相同、随机阵容，各 20 张地图）：能力差 2 → 65%，差 5 → 75%，仍在目标附近（样本误差约 ±11%）。
- **12 英雄 + 属性改版后的复核**（2026-11-25，两队英雄相同、随机阵容，每项 40 张地图，每次换种子）：

  | 灵敏度 | 能力差 2 | 能力差 5 | 生疏对精通 |
  |---|---|---|---|
  | 0.35（原值） | 45% | 72% | 43%（生疏系数 0.88）、33%（0.80） |
  | 0.5 | 45% | 70% | 30%（0.86） |
  | 0.6 | 75% | 78% | 58%（0.89） |
  | 0.7 | 78% | 80% | 40%（0.90） |

  - 不同种子之间的波动很大（同一设置相差可达 20 个百分点，阵容由种子决定），40 张地图的样本还不足以精细校准。
  - 暂定**灵敏度 0.55、生疏 0.87、熟悉 0.94**，预计能力差 2 约 60–65%、差 5 约 75%、生疏对精通约 35–40%。
  - 待办：用 `tools/run_curves.py` 跑大样本（每项 120 张以上、多组种子）复核。
- 联赛「直接出结果」的模型直接按目标曲线校准（每回合胜率 = sigmoid(0.112 × 能力差)），不受上面波动的影响，见 `赛事层设计.md`。
- 批量模拟默认让 A 队按种子奇偶交替左右两边，避免地图和出生点的不对称影响结果（`--fixed_sides` 关闭交替）。

**未完成的指标**：
- 决断和心态还没有独立的可观测指标：决断的效果体现在团队对战力的误判上，心态只在压力局面生效。需要在阶段 2 补指标，例如「劣势开团次数」「压力回合与普通回合的指标差」。

**符文的发现**：两队英雄相同时，对战非常敏感。一整页示例属性符文（共约 +5 攻击、+120 生命、+1.5 护甲，约 5% 的属性优势）就能赢下约 80% 的地图。阶段 3 设计符文数值时要考虑这一点，有两种方向：
- 把满页符文的总强度控制在约 2% 属性；
- 或者接受「符文是重要的养成差距」，靠禁选来抵消。
