# NeonMOBA · 核心对战规则 v2 与选手属性设计（已确认）

> 状态：设计已确认，阶段 1 实现中。取代原「生存刷怪 + 3V3 竞技场」两阶段方案。原生存模式转为经营层的训练模式。

## 一、核心对战：回合制 3V3

- **赛制**：BO3 系列赛；每张地图先赢 4 回合（最多 7 回合）。赛前先禁选地图，再禁选英雄（每队禁 2 选 3）。
- **回合**：每回合 75–100 秒，开局有 15 秒购买和布阵。每回合开始时所有技能冷却重置。
- **地图机制即获胜条件**：一张地图对应一种机制，后续逐步扩充。全歼对方在任何机制下都直接获胜。
  - 占领核心（首个）
  - 待做：护送载荷、击破水晶、抢夺能量球、坚守倒计时
  - 不同机制偏好不同阵容，地图禁选因此是博弈的一环。
- **没有局内升级、小兵和打钱**。英雄成长只来自装备。
- **装备**：
  - 6 格；输掉回合或阵亡都不会损失装备。
  - 后期需要装备升级或合成层，避免满装后钱没处花（待设计）。
- **经济**：
  - 胜方每回合 +2500。
  - 败方按连败数 +1500 / 2000 / 2500 / 3000。
  - 败方每次输掉回合后，可以一次性按 100% 原价出售装备，用于转型针对对方。
- **技能**：保持冷却机制，不使用大招充能点，保留英雄设计的灵活性。

### 阶段 1 原型的实际参数（`game/rounds.gd`，可调）

| 参数 | 值 | 说明 |
|---|---|---|
| 购买阶段 | 15 秒（第 1 回合 25 秒） | 英雄被限制在出生区内；商店只在购买阶段可用 |
| 核心开放 | 开战后第 20 秒 | 原设计 30 秒，实测双方会在核心开放前就打完，所以提前 |
| 占领 | 无人争夺时 8 秒占满；第 60 秒起速度翻倍 | |
| 回合时限 | 开战后 80 秒 | 时间到时比占领进度，其次存活人数，再次剩余血量 |
| 英雄等级 | 固定 12 级，技能自动加点 | |
| 回合内血量倍率 | ×2.0 | 控制团战时长；实测开战阶段中位数 65 秒 |
| 初始金钱 | 3000 | |
| 击倒 / 助攻 | +150 / +50 | 原设计没有，原型先加上以鼓励交战，可删 |
| 回合结束方式 | 实测（相同阵容）：时间到 38%、占领核心 41%、全歼 21% | |

AI 在核心开放前会守住卡位线，只有明显占优（战力 ≥ 对方 1.3 倍）才开团；核心开放后按占领紧迫度争夺。

## 二、选手属性（四层）

### 1. 通用能力（6 项，1–20 分）：决定 AI 的执行质量

每项能力必须对应可量化的对战指标。批量模拟时，提升单项能力必须能在对应指标上观测到变化，否则视为没有接入，需要修正或删除。

| 能力 | 驱动的 AI 行为 | 验证指标 |
|---|---|---|
| 反应 | 躲预警技能的概率和延迟；被突进后交保命技的速度 | 可躲技能的躲避率；被控到交技能的延迟 |
| 操作 | 弹道瞄准误差（aim_err）；连招衔接；取消前后摇 | 弹道技能命中率；连招完成率；单位时间伤害 |
| 意识 | 目标优先级判断；站位是否避开对方技能范围；察觉侧翼 | 对高优先级目标造成的伤害占比；在可避免位置承受的伤害 |
| 决断 | 撤退血线（不再固定为 0.18）；开团时机；是否过度追击 | 冒进阵亡率；开团成功率；残血撤退成功率 |
| 配合 | 响应集火和开团指令的延迟；控制接力是否叠控；保护队友 | 集火重合度；控制重叠浪费时间；对标记指令的响应延迟 |
| 心态 | 压力情境（赛点、残局、连败）下其余五项的波动幅度 | 压力回合与普通回合的指标差 |

玩家亲自操控某名选手时：反应、操作、意识、决断由玩家本人替代；配合和心态继续作用于 AI 队友，决定队友对玩家标记的响应。

### 2. 英雄熟练度（每个英雄单独计）

| 阶段 | 能力发挥系数 | 解锁的 AI 打法 |
|---|---|---|
| 生疏 | 70% | 每个技能只按最主要的用途使用 |
| 熟悉 | 85% | 技能的所有推断用途都会使用 |
| 精通 | 100% | 主动打连招（prefer_status / setup_status） |
| 大师 | 105% | 发挥系数更高（**不再**解锁招牌特质） |

- **专属能力只属于擅长英雄**（见 `经营与养成设计.md` 第四节），不由熟练度解锁。
- **衰减**：长期不使用的英雄熟练度会缓慢下降；擅长英雄衰减更慢。

### 3. 特质（每人 1–3 个）

在特定情境下触发的修正，用来制造故事，例如：残局之王、大赛型、慢热、开团手、英雄池狭窄。

### 4. 状态

- 心态值在比赛中实时浮动：被单杀、连败会下降，残局获胜、高光击杀会上升。
- 偏离常态时，各项能力随机波动的幅度变大。
- 战术暂停（每张地图 2 次）可以拉回心态。

## 三、训练模式（原生存模式）

- **英雄训练**：提升指定英雄的熟练度（擅长英雄 ×2）。
- **能力训练**：
  - 弹幕关卡 → 反应
  - 优先目标关卡 → 意识
  - 技能命中挑战 → 操作
  - 三人小队训练 → 配合
- **取舍**：训练时间按周限量，熟练度会衰减。
- **玩家亲自训练**：按表现评分转换成成长值，效率高于自动训练。

## 四、验证目标（批量 AI 对 AI 模拟）

1. **能力差距与胜率**：平均能力差 2 分时胜率约 60%，差 5 分时约 80%；爆冷率 20–30%。
2. **熟练度**：同一选手用生疏英雄和精通英雄，胜率差约 10–15%。
3. **单项能力**：6 项能力单独提升时，都要在各自的验证指标上有可观测的变化。

工具：`sim/sim_cli.gd`（`--mirror` 两队用相同英雄，只比选手能力）和 `tools/run_curves.py`。
