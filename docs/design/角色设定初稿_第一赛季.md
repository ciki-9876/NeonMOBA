# NEON DRIFT · 角色设定初稿（第一赛季）

> 状态：初稿（2026-11-26），供讨论和修改。格式按 `角色设计规范.md`。
> 范围：第一赛季登场的 15 名核心角色、8 支战队的阵容、前世大事年表。
> 前 8 张卡片写完整；后 7 张先写关键要素，标「待补全」的部分下一版补。
> 能力六项按「反应 / 操作 / 意识 / 决断 / 配合 / 心态」顺序；性格五项按「野心 / 忠诚 / 物欲 / 自尊 / 合群」顺序，都是 0–20 和 0–10。

## 一、世界设定

**时间**：不写具体年份。主角在前世「第五赛季世界赛决赛之夜」重生，回到第一赛季开赛前一个月。前世的记忆覆盖 S1–S5；**S6 之后的事，主角也不知道。**

**联赛**：第一赛季联盟扩军到 8 队。星火网咖队拿下城市赛冠军，抢到最后一个名额，前世也是这样。

> 待确认：联赛层级（城市赛、次级联赛、世界赛）还没定，本稿先按「只有一个 8 队职业联赛，季后赛冠军代表赛区去世界赛」来写。

## 四、核心角色（完整卡片）

### 1. 主角 · 江驰「Ash」

| 项 | 内容 |
|---|---|
| 身份 | 选手 · 输出 · 星火首发 · 19 岁（玩家可改名） |
| 一句话 | 重来一次的人 |
| 外观 | 乱发、连帽衫、左手腕旧护腕；代表色：余烬橙 |
| 能力 | 13 / 14 / 10 / 8 / 9 / 8（平均 10.3） |
| 潜力 | 16–18；标准型；侧重意识、决断（前世缺的正是这两项） |
| 英雄 | 擅长：霓虹漂移者；绯刃 60，烬星 45，鹰隼 30 |
| 性格 | 9 / 7 / 3 / 8 / 6。主角的性格由玩家的选择塑造，这里只是开局值，不用于 AI 判断 |
| 名气 | 3 |

**说话风格**：前世的他嘴硬冲动，重生后多了一份沉稳，偶尔说出不像 19 岁的话，队友会觉得奇怪。
- 私信：「今晚加训，我请宵夜。」
- 赢了：「这才第一步。」
- 被挖角：「我不会离开星火。这次不会。」

**背景**：小城网吧长大，操作天赋高，16 岁和 Zero 一起参加天穹青训，Zero 留下了，他被刷掉。之后在网吧和大熊、小鱼组了队。
**前世结局**：S1 星火垫底解散后，在次级联赛漂了三年，24 岁手腕伤病退役，回星火网咖当网管。看着 Zero 一次次捧杯。
**今生可能**：带兄弟们夺冠 / 成为传奇选手 / 提前转型为教练或老板 / 再次失败。

**关系**：大熊（兄弟，3）、小鱼（兄弟，3）、Zero（宿敌，3，青训落选）、老周（上下级，2，前世收留他）。

**原本轨迹**：S1 星火垫底 → 休赛期解散 → S2–S4 次级联赛 → S4 手腕伤病退役 → S5 网管。

**专属剧情**：开场教程（前世 S1 最后一场必输的比赛）；重生之夜。

### 2. 大熊 · 熊磊

| 项 | 内容 |
|---|---|
| 身份 | 选手 · 坦克 · 星火首发 · 21 岁 |
| 一句话 | 网吧里最能扛的胖子 |
| 外观 | 寸头、大块头、洗白的旧队服；代表色：土黄 |
| 能力 | 8 / 9 / 10 / 9 / 13 / 11（平均 10.0） |
| 潜力 | 13–15；晚成型；侧重意识、配合 |
| 英雄 | 擅长：重锚（专属能力「巨锚」）82；铁壁 55，霜铠 40，磁轨 25 |
| 性格 | 3 / 9 / 6 / 4 / 8 |
| 名气 | 2 |
| 合同 | 1 年，低薪 |

**说话风格**：憨厚、话不多，口头禅「没事，我扛着。」
- 私信：「今天我妈又打电话了……没事，我扛着。」
- 赢了：「嘿嘿，烧烤走起？」
- 被挖角或谈判：「我不懂这些，你们定吧。我就想跟着阿驰打。」

**背景**：家里开早餐店，父亲身体不好。打游戏是唯一的爱好。
**前世结局**：S1 结束后退役去送外卖，供弟弟上学。后来再没碰过比赛。
**今生可能**：成为星火的定海神针 / 被更强的坦克替下，转做替补或青训教练 / 因为家庭压力离开。

**关系**：主角（兄弟，3）、小鱼（朋友，2，把小鱼当弟弟）、阿岩（竞争，1，如果玩家签了阿岩）。

**原本轨迹**：S1 第 5 周家里催他回去帮忙（前提：星火没有给他加薪）→ S1 休赛期退役。

**前世笔记**：「大熊 S1 之后就退役了，因为家里缺钱。」（清楚，开局就记得）

**专属剧情「妈妈的电话」**：S1 第 5 周，大熊说家里让他回去。
- 加薪留人：花钱，大熊忠诚 +1、心态稳定。
- 去他家帮忙说服：占用一周训练，和大熊的关系 +1，以后不会再提。
- 放他走：省钱，换来一个空位；小鱼心态 −2，主角和小鱼的关系 −1。

- 放人换转会费：得到一大笔钱；小鱼前往天穹（如果不改变，他会重复前世的命运）；大熊的心态 −2。
- 让小鱼自己决定：按小鱼的性格和星火当前成绩，由小鱼自己选。

## 六、开局候选人的设计意图

| 候选人 | 路线 | 前期 | 后期 | 代价 |
|---|---|---|---|---|
| Rin（输出） | 接班人 | 只能当替补 | 主角转型后接班，联赛顶级输出 | 野心大、忠诚低，成绩不好会走 |
| 阿岩（坦克） | 兄弟传承 | 最弱 | S2 后期起成为顶级坦克 | 终有一天要在他和大熊之间选首发 |
| Mute（辅助） | 高风险天才 | 能力最高但配合拖后腿 | 打开心扉后成为顶级辅助 | 合群 1，需要剧情投入；和小鱼竞争 |
| 路人 2–3 名（每局随机） | 不依赖前世记忆 | 平庸 | 看运气 | 没有剧情，但可能有隐藏潜力 |

三个人都是「记忆里的名字」，不选的人会按原本轨迹走：Rin 去极光，阿岩去深空，Mute 去幻影。之后在联赛里遇到他们，也是一种剧情回响。
