# NeonMOBA · 英雄设计体系 v2（3C 版，已确认 2026-11-25）

> 3C 实验（`3C实验_狙击手.md`）验证了「WASD 移动 + 鼠标瞄准」的手感，全部英雄按这套操作重做。
> 本文是新英雄设计规则的准绳；做法和流程见 `docs/新英雄制作规范.md`。

## 一、操作（玩家与 AI 相同）

| 输入 | 作用 |
|---|---|
| WASD | 移动；角色始终朝向鼠标（不再有转身速度） |
| 鼠标 | 瞄准点 |
| 左键（按住连发） | 普攻 |
| 右键 | 英雄的特色技能；可蓄力的技能按住蓄力、松开释放 |
| Q / E / R | 技能，朝鼠标方向或位置释放；R 为大招 |

- AI 通过同一套「虚拟手柄」操作英雄（移动方向、瞄准点、开火、按住）。所以玩家能做到的，AI 用同样的方式做。
- 对敌的指定目标技能取消：改为方向技能或地点技能。
- 对友方技能自动锁定离鼠标最近的友方英雄（施法距离内），没有就作用于自己。

## 二、属性与数值

- **只有二级属性**（2026-11-25 起，详见 `属性与装备迭代设计案.md`）：
  - 没有力量、敏捷、智力。每个英雄有一套固定面板 `stats`（生命、攻击力、攻击间隔、物防、法防、法力、生命回复、法力回复、移速）；
  - **升级只给技能点，不加属性**。属性只来自装备、符文和被动技能；
  - 普攻伤害 = 攻击力，攻击间隔 = 英雄攻击间隔 ÷（1 + 攻速%），不消耗蓝量；
  - 物理防御和法术防御：减伤 = 防御 ÷（防御 + 100）；
  - 技能强度 `pow`：所有技能的伤害、治疗、护盾 ×（1 + 技能强度%），普攻和装备特效不受影响。
- **攻击距离**：
  - 远程：仅表示射击范围。普攻弹道最远飞行距离 = 攻击距离 × 1.5，不做伤害衰减。初始值偏小（约 440–480），保证弹道最远距离在视野范围内。
  - 近战：攻击距离就是普攻扇形的半径。**近战只获得攻击距离加成的一半**（装备 +100，近战只 +50）。
- **弹道速度**（新属性）：远程普攻弹道的飞行速度，装备和符文可以加（属性键 `pspd`）。
- **视野**（新属性，`vision`）：
  - 对 AI：感知范围。全队共享视野，看不见的对手不会被感知、也不能被选为目标。草丛规则照旧叠加：视野内的草丛仍然藏人。
  - 对玩家：镜头高度。视野越大镜头越高、看到的越多；有上限，不会高到看不清战场。
  - 换算：缩放 = 360 /（视野 × 0.6），限制在 0.55–1.0。蓄力技能可以在蓄力时临时再拉高镜头（技能里的 `zoom`），最低到 0.45。
  - 参考值：坦克 850，输出 950，辅助 1000。

## 三、普攻

| | 远程 | 近战 |
|---|---|---|
| 形式 | 朝鼠标方向射出直线弹道，**不追踪**，命中第一个对手 | 朝前方挥出扇形 **范围伤害**，扇形内所有对手各受一次完整伤害 |
| 距离 | 最远飞行距离 = 攻击距离 × 1.5 | 半径 = 攻击距离 |
| 其他 | 被立柱和墙挡住 | 扇形角度由英雄决定（参数 `arc`，默认 100°）；吸血、暴击、攻击特效对每个目标分别生效 |

- 前摇（`atk_point`）和后摇（`backswing`）保留，随攻速缩短。前后摇期间可以移动。
- 平衡提示：近战天然擅长团战，基础攻击力可以略低于同级别的远程。

## 四、技能槽

| 槽 | 内部键 | 规则 |
|---|---|---|
| 右键 | `w` | **一定是主动技能，不能升级**，开局就有。伤害和治疗类效果通常不写固定值，而是和属性挂钩（见下），这样能随装备成长。**优先放英雄的特色技能**（如狙击手的瞄准射击） |
| Q / E | `q` / `e` | 设计逻辑不变，可升级 4 级，可以是被动技能 |
| R | `r` | 大招，6/12/18 级可学，可以是被动技能 |

> 内部键沿用 `w`，是为了让符文、AI 和数据格式不用改。界面上显示为「右键」。

**属性挂钩的数值**：任何数值参数都可以写成：

```
{"v": 基础值（或按等级的数组）, "atk": 系数 × 攻击力, "hp": 系数 × 最大生命, "charge": [无蓄力倍率, 满蓄力倍率]}
```

- 物理输出挂攻击力，例：`"dmg": {"v": 30, "atk": 0.72}` = 30 + 0.72 × 攻击力，提示文字自动写成「30 + 0.72×攻击力（当前 93）」；
- 坦克挂最大生命，例：`"amt": {"v": 30, "hp": 0.05}`；
- 法师和辅助写固定值（例如治疗 126），由技能强度统一放大。

**蓄力技能**：技能上加

```
"charge": {"time": 蓄满秒数, "min": 最低蓄力（低于则取消，不进冷却）, "move": 蓄力时移速倍率, "zoom": 满蓄力时镜头额外拉高的倍率}
```

带 `"charge"` 倍率的参数随蓄力从无蓄力倍率变到满蓄力倍率。

改造要点：
- 原来的 W 技能大多移到 Q；每个英雄最有特色的技能放到右键。
- 原来的点选单位技能改成方向技能：铁壁的盾冲改为冲向鼠标；星语的星缚改为弹道；绯刃的大招改为从鼠标附近的对手开始连斩。
- 漂移者和绯刃有手写技能脚本，已改写为 3C（`cast(s, tgt, pos, chg)`），其中漂移者的光束会被地形挡住。
- 新英雄磁轨、鹰隼、回响是纯数据英雄；鹰隼就是 3C 实验里的狙击手「鹰隼」，按正式英雄的规则改写。
- **制作鹰隼时的教训**：第一版（单体狙击 + 翻滚 + 小范围雷 + 单体大招）在 AI 对战里只有约 5–18% 胜率，换任何单项数值都没用。逐项替换技能后发现，AI 对 AI 时**范围伤害和控制**的价值远高于单体伤害，所以给它的每个技能都补了控制（狙击减速、雷定身、大招晕眩），并把位移翻滚换成生存被动。新英雄至少要有一个范围或控制技能。

## 六、回合制的相关调整

- 回合内血量倍率从 2.0 改为 0.8：普攻不再必中，原来的血量下几乎打不死人。
  - 只有首批 3 个英雄时定为 0.7：占领约 70%、团灭约 28%。
  - 9 个英雄全部加入后，漂移者、绯刃这类爆发英雄让团灭升到约 65%，所以调回 0.8：占领约 59%、团灭约 41%，开战阶段中位数约 46 秒，每回合约 2.4 次击倒。
- 2026-11-26 对战手感调整：普攻弹速 ×1.35、技能弹速 ×1.3、英雄体积 ×1.3、移速 ×0.88（`game/tuning.gd`），血量倍率 0.8 → 0.55，加入读秒复活。远程普攻命中率 42% → 58%，TTK 6.4 → 4.8 秒，占领约 44%、团灭约 56%。详见「核心对战规则与选手属性设计」。英雄数据表里的弹速、半径、移速是乘倍率之前的数值。
- 能力换算的灵敏度需要重新校准：瞄准误差和躲避现在作用在每一发普攻上，能力差距的影响明显变大。校准结果见「核心对战规则与选手属性设计」。
