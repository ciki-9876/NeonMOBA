# NeonMOBA · 经营与养成设计（已确认）

> 状态：设计已确认。符文和选手专属能力的**接口**已在阶段 1 实现，各做了示例；具体内容在阶段 3 制作。

## 一、原则

1. **只强化「人」和「信息」，不直接强化英雄数值**。符文是唯一的例外，只给少量属性和机制改造，并且 AI 战队同样拥有，所以不影响平衡。
2. **要有取舍**：货架随机刷新，选手和教练有持续工资，设施有维护费，钱永远不够用。
3. **构筑思路**：符文 + 选手（擅长英雄）+ 训练 → 打造自己擅长的英雄池 → 通过禁选保证拿到自己擅长的体系 → 赢下比赛。

## 二、局内（一次生涯）的商品与资源

| 类别 | 内容 | 取舍 |
|---|---|---|
| 人员 | 签约选手、买断转会、青训苗子 | 签约费 + 每周工资 |
| 教练组 | 主教练 1 + 助教 2；**每名教练带 1–2 个教练技能**（原「战队文化」） | 工资；任期越长技能越强 |
| 设施 | 训练室、外设、宿舍、数据中心、健身房 | 一次性投入 + 维护费；也是基地外观的成长线 |
| **英雄符文** | 战队所有、按英雄配置，见第三节 | 钱和槽位有限，深练几个英雄还是铺开英雄池 |
| 赛前道具 | 情报报告、战术卡（如首回合经济 +500、额外一次暂停、心态护符） | 一次性 |
| 主角专属 | 高级 HUD 插件、训练软件：只增加信息（对手冷却、清晰预警、小地图标记） | 不加数值 |
| 情绪价值 | 基地装修、队服队标、英雄皮肤、主角的车和房、奖杯墙、庆功宴（全队心态 +1 一周） | 纯享受 |

**货架形式**：基础设施和人员固定可买；稀有商品（特殊选手、外设、稀有符文）随机刷新。

**收入来源**：
- 比赛奖金；
- 赞助商：有要求，完不成要赔违约金；
- 直播和周边；
- 赛事竞猜：不能押自己的比赛，否则触发假赛丑闻事件。包装成「赛事竞猜 / 预测活动」，设投入上限；如果在国内上线，需要提前评估审核风险。

**教练技能示例（原战队文化）**：
- 经济流：「勤俭持家」败方补偿再 +500；「强起专家」经济局全员决断 +2。
- 残局流：「残局文化」最后一人存活时反应、操作 +3。
- 单核流：「众星捧月」一人全能力 +2，其余两人 -1。
- 英雄池流：「百变」每人精通英雄数上限 +2。
- 青训流：「青训体系」新人成长 ×2。

## 三、英雄符文

- **归属**：归战队所有、按英雄配置；谁用这个英雄都能享受它的符文页。AI 战队按联赛档次生成符文。
- **三类槽位**：
  - **属性槽**：小幅属性，可以叠加，有上限（例如每层生命 +40，最多 5 层）。
  - **技能槽**：从 2–3 个技能改造里选 1 个，例如「Q 减速 +0.3 秒」。
  - **核心槽**：稀有的特殊能力。
- **实现方式**（阶段 1 已完成）：符文就是一组改动，在开局时应用到英雄身上，格式见 `game/runes_db.gd`。
  - 加属性；
  - 改技能参数：顶层参数，或者所有某类效果积木里的参数；
  - 给技能追加效果积木。
  - 纯数据英雄天然支持；手写技能脚本的英雄可以改顶层参数。
- **平衡目标**：一整页满符文带来的胜率提升不超过约 5%，用批量模拟校准。

## 四、选手擅长英雄与专属能力

- **擅长英雄**：每名选手天生 1–3 个，是生成时决定的，基本练不出来；只有极少数剧情事件能「顿悟」出新的。
- **专属能力**：每个英雄准备 2–3 种可能的专属能力，每名选手随机拥有其中一种，所以同一个英雄在不同选手手里也不一样。只有擅长英雄才有专属能力。
- **训练加成**：擅长英雄的熟练度成长 ×2，衰减更慢。
- **AI 风格**：AI 用擅长英雄时有个人打法倾向（阶段 3）。
- **与熟练度的关系**：熟练度「大师」阶段不再解锁招牌特质，只保留发挥系数（105%）和 AI 打法解锁。
- **信息**：知名选手的擅长英雄是公开的；无名新人的需要球探或「慧眼识珠」才能看到。
