# NEON DRIFT · 周末事件设计（赛季中的事件节点）

> 状态：草案（2026-11-26），待确认。
> 定位：赛季里除了「训练 → 情报 → 系列赛」之外的生活化节点，类似肉鸽游戏地图上的事件节点、奇遇节点、商店节点。
> 原则：占比不大（每两周一次，每次 1–3 分钟）；每次都是一个小的取舍；尽量和角色、前世记忆挂钩，而不是孤立的小游戏。
> 依赖：条件和效果的词汇沿用 `角色设计规范.md`；属性的含义见 `角色机制设计.md`；呈现形态见 `界面形态设计.md`。

## 一、在赛季里的位置

| 时间 | 内容 |
|---|---|
| 常规赛第 1 周 | 训练 → 情报 → 系列赛 |
| 常规赛第 2 周 | 训练 → 情报 → 系列赛 → **周末** |
| 第 3 周 | 训练 → 情报 → 系列赛 |
| 第 4 周 | …… → **周末** |
| 第 5 周 | …… |
| 第 6 周 | …… → **周末** |
| 第 7 周 | …… |
| 季后赛前 | **备战周末**（选项偏向备战、调整心态） |
| 半决赛、决赛 | 训练 → 情报 → 系列赛 |
| 休赛期 | **3 个假期节点**，加上转会、续约、颁奖等休赛期内容（第十节） |

每个赛季 4 个周末加 3 个假期节点，一局生涯（4–6 个赛季）大约 30–40 个节点。

## 二、一个周末怎么进行

1. **周五晚上，手机群聊**：队友在战队群里各自提议周末去干什么，每个提议就是一张选项卡，共 2–3 张。偶尔会有群外的人私信一个额外选项，例如老周转来一个商业赛邀请，或者某个角色约你见面。
2. **玩家选一个**。另外永远有一个保底选项「宅着休息」：全员疲劳 −20，没有其他效果。
3. **事件进行**：按事件的类型，用文字对话、剧情插图或小玩法呈现，中间可能有 1–2 次选择。
4. **结算卡**：显示这次周末带来的变化，例如关系、满意度、名气、金钱、新的前世笔记。

**取舍**：选了任何活动，就放弃了「宅着休息」的疲劳恢复。所以队伍疲劳很高时，玩家要在「玩得开心」和「下周别累垮」之间选择。

## 三、节点类型

| 类型 | 类比肉鸽 | 主要收益 | 主要代价 |
|---|---|---|---|
| **团队活动** | 营火 | 队友之间关系、满意度 | 金钱、少量疲劳 |
| **角色事件** | 剧情节点 | 推进某个角色的剧情，改变他的走向 | 往往要放弃别的收益 |
| **外出社交** | 事件节点 | 接触其他战队的角色：挖角铺垫、情报、触发前世记忆 | 有风险：被拍到、被利用 |
| **小玩法** | 精英战 / 挑战 | 金钱、名气、发现新人，玩家的操作水平有用 | 疲劳；输了掉状态或名气 |
| **集市** | 商店 | 外设、战术卡等道具，货架随机刷新 | 金钱 |
| **奇遇** | 稀有事件 | 稀有收益：潜力 +1、隐藏导师、特质、关键情报 | 往往是赌博，可能有负面结果 |

每次 2–3 张选项卡尽量来自不同的类型。

## 四、地点

周末发生在城市里的固定地点，每个地点一张像素风场景图，反复使用。地点随名气和剧情逐步解锁，战队搬进新基地后会多出新的地点。

| 地点 | 解锁 | 常见事件 |
|---|---|---|
| 星火网咖 | 开局 | 通宵开黑、网吧擂台、神秘高手、老周的唠叨 |
| 江边烧烤摊「老地方」 | 开局 | 团建、偶遇其他战队的选手、深夜谈心 |
| 电子城 | 开局 | 集市（外设、战术卡）、砍价 |
| 大熊家的早餐店 | 和大熊的剧情 | 大熊的家庭事件 |
| 江边公园 | 开局 | 散步谈心、晨跑（疲劳恢复）、偶遇 |
| 商场中庭 | 名气 ≥ 20 | 商业表演赛、粉丝见面会 |
| 联赛场馆 | 进入联赛 | 观看别队比赛、赛后偶遇对手、媒体采访 |
| 直播基地 | 名气 ≥ 30 | 直播、和主播合作 |
| 老家 | 休赛期 | 回家过年、亲人 |

## 五、小玩法

每个小玩法 1–3 分钟，都可以选择直接出结果（和比赛一样）。尽量复用已有的系统。

| 小玩法 | 玩法 | 复用 | 收益和风险 |
|---|---|---|---|
| **网吧擂台** | 主角 1V1 单挑网吧里的挑战者，先赢 2 局 | 对战引擎（需要加 1V1 小地图模式） | 赢：金钱、名气；有概率挑战者是隐藏的好苗子（路人候选人）。输：状态 −1 |
| **商业表演赛** | 3V3 短局，先赢 2 回合，可以用平时不练的英雄 | 对战引擎、回合制 | 金钱 +800–1500、名气 +3；用到的英雄熟练度 +；疲劳 +10 |
| **直播** | 手机界面：选直播内容，回答 3 轮弹幕提问（选项） | 手机界面、新闻系统 | 名气 +，可能有打赏收入；回答不当会翻车（名气 −、上热搜） |
| **电子城砍价** | 和摊主对话，3 轮出价和说辞 | 手机或对话界面 | 便宜买到外设；砍过头了摊主不卖 |

## 六、生成规则

- **数量**：每个周末 2–3 张选项卡，加上保底「宅着休息」。
- **类型不重复**：同一个周末的选项卡尽量来自不同类型。
- **权重随状态变化**：
  - 队伍平均满意度低 → 团队活动更容易出现；
  - 钱少 → 商业表演赛、商业邀请更容易出现；
  - 下周对手很强、或者即将进季后赛 → 偏向备战类（看对手录像、封闭训练）；
  - 有角色的专属事件到了时间 → **必定**作为选项之一出现（不强制选）。
- **稀有度**：普通 70%、稀有 25%、传说 5%。连续 3 个周末没出现稀有以上的选项，下一个周末必出一个（保底）。
- **不重复**：同一个事件每个赛季最多出现一次；标为「唯一」的事件一局生涯只出现一次。
- **可复现**：抽取用赛季种子，和训练、比赛一样可复现（读档后不会刷出不同的选项）。

## 七、效果的尺度

| 收益 | 普通事件 | 稀有 | 传说 |
|---|---|---|---|
| 关系 | +5–10 | +15 | 结成师徒、化敌为友 |
| 满意度 | +5–10 | +15 | — |
| 名气 | +2–5 | +8 | +15 |
| 金钱 | ±几百 | 1000–3000 | 一笔大钱或长期赞助 |
| 能力 | 不直接加 | 某项经验 +50% | 潜力上限 +1、获得特质 |
| 信息 | — | 下个对手的禁选倾向 | 新的前世笔记、某人的隐藏性格 |

- 一个普通周末的总价值大约是**半周训练**。周末不能替代训练，只是锦上添花和提供剧情。
- 负面结果要有，但大多是可选择的风险（例如「去赞助商饭局」），而不是突然的惩罚。

## 八、事件示例（第一版事件池）

| 前世的梦 | 角色事件（主角） | — | 主角状态低迷时 | 梦见前世的失败。心态经验 +，或者想起一条前世笔记 |

## 九、和其他系统的接口

- **数据**：周末事件写在 `game/story/events_db.gd`，`kind` 为 `weekend`，比普通事件多几个字段：

  ```
  "bbq_by_river": {
  	"kind": "weekend", "type": "team", "loc": "bbq", "rarity": "common", "unique": false,
  	"if": [], "weight": [["team_satisfaction", "<", 50, 2.0]],     # 满足时权重 ×2
  	"proposer": "bear",                                            # 群聊里由谁提议（可空：系统随机选一名队友）
  	"text": "……", "choices": [...],
  }
  ```

- **新增的效果词汇**（要加进 `角色设计规范.md` 的词汇表）：`item_add`（获得道具）、`recall`（得到一条前世笔记）、`scout_reveal`（看到某人的隐藏性格或潜力范围）、`unlock_loc`（解锁地点）、`minigame`（启动小玩法，结果再接后续效果）、`fatigue`（疲劳增减）。
- **新增的条件词汇**：`weekend_index`（第几个周末）、`weather`（天气，可选）、`loc_unlocked`。
- **道具**：外设（长期的小加成，占「外设」槽位）、战术卡（一次性，赛前使用），归入经营层的赛前道具。
- **前世笔记**：周末是触发「见到本人后想起」的主要场合。

## 十、休赛期的假期节点

休赛期有 3 个节点，规则和周末相同，但事件池不同：

- 回老家过年（主角和队友各自回家，回来时有家里的事件）；
- 出国集训（花钱，能力经验 +，外籍选手满意度 +，语言 +）；
- 颁奖典礼、联盟年会（遇到所有战队的人，社交和挖角的主要场合）；
- 粉丝节、商业代言（名气高时）。
